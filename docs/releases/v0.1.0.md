# avirx 0.1.0

The first stable avirx release.

- Build immutable, typed HTTP requests on the web-standard `fetch` API.
- Validate contract parameters and responses with parser-compatible schemas.
- Inspect requests safely through previews and redacted cURL output.
- Compose auth, timeout, retry, hooks, caching, concurrency, and rate limiting.
- Run with zero runtime dependencies in Node.js 18.17+ and modern browsers.
- Ship a domain-organized implementation guarded by its exact public API and package shape.
